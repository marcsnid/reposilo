Appearance

Tint cards, panels, and notification markers with each repo's own color. Turn off to give every card the same theme color.

Notifications

A JSON POST on new releases and dead remotes.

Alerts older than this are dropped. 0 keeps everything. Long-term history lives in Stats and OTLP.

Retention

How much history to keep per repo. -1 keeps everything, 1 keeps only the newest. Per-repo overrides live on each repo page.

Per-tag retention rules ([[retention.tag_rules]]) are set in the config file.

Tags

When enabled, forge-suggested tags (e.g. GitHub topics) are added to a repo automatically, alongside any tags you enter yourself.

When enabled, the folder a repo is placed in is split into tags. Putting a repo in games/tools adds the tags games and tools alongside any tags you enter.

Repository icons

Download the repo owner's avatar (GitHub, GitLab, Forgejo) and store it in the archive as the repo icon. Disable to skip the extra API call and storage; existing icons are kept.

Release binaries

Also download the binary files attached to releases, not just the source snapshot. Assets are matched by filename, so foo-win64.zip, foo-x86_64-unknown-linux-gnu.tar.gz and foo_1.2_amd64.deb all work. Source tarballs and files without an OS and arch in the name are skipped. Leave everything unchecked to disable.

Scheduler

How often the background loop checks remotes. Unchanged repos cost a single ls-remote; nothing is cloned unless something moved.

A remote unreachable for this many consecutive days is marked dead and the scheduler stops contacting it. 0 = never declare dead. A manual refresh resurrects it if it ever comes back.

Scheduled checks

Hash every stored zip against its sidecar hash on a schedule to catch missing or corrupt files. Off by default: a check reads the whole archive, so skip it if your storage already guards against bitrot (ZFS, btrfs, and similar).

llama.cpp

Any OpenAI-compatible endpoint. Used for auto-tagging and import review.

OpenTelemetry

Optional: push telemetry (logs, metrics, traces) to an OTLP/HTTP collector. The built-in Stats page always works without this.

Rate limiting

Space outbound requests per host so a burst of repos does not trip a forge's rate limiter. Applies to API calls and git operations. Local and file:// remotes are never paced.

Instance

Fixed for the running server: edit the config file and restart to change these.

Tokens and the archive layout are set in the config file, not here. Tokens support env:VAR so the secret never lives in the file.
