Import a zip collection

Point reposilo at a folder of zipped repositories. Each zip is inspected offline (.git config, package manifests, README). Detected repos land in the archive with their origin; the rest can be parked as unknown (still taggable & browseable) or identified with GitHub search suggestions. Imported zips are never touched by retention pruning.
